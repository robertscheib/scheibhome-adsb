# Raspberry Pi Attic ADS-B Layout Recommendation

**Date:** 2026-07-22
**Author:** Codex

## Recommendation

Some physical separation between the ADS-B antenna/RTL-SDR and the Raspberry
Pi is desirable. However, at 1090 MHz it is generally better to extend USB or
Ethernet than to add a long run of lossy antenna coax.

The preferred arrangement is:

```text
Attic antenna
    |
short coax
    |
RTL-SDR
    |
shielded active USB extension, if needed
    |
Raspberry Pi in conditioned space
    |
wired Ethernet
```

This keeps the sensitive RF path short while separating the antenna and SDR
from noise generated by the Pi, its power supply, USB peripherals, and NVMe
storage. The SDR-Enthusiasts ADS-B equipment guide describes a similar layout,
with the antenna and SDR near the roof and an active USB cable running to the
computer:

<https://sdr-enthusiasts.gitbook.io/ads-b/intro/equipment-needed>

## Layout for the purchased magnetic antenna

The purchased Kaunosta antenna kit includes a fixed 1.5-meter RG174 cable. That
cable already provides reasonable separation between the antenna and Pi.

Install it as follows:

1. Place the magnetic antenna vertically on a large steel ground plane, such
   as a steel baking sheet or suitable metal HVAC surface.
2. Position the antenna as high as practical and near an exterior-facing area,
   while avoiding foil-backed insulation, metal ductwork in its line of sight,
   and other obstructions.
3. Extend the supplied cable away from the Raspberry Pi rather than coiling it
   beside the Pi, its power supply, or an NVMe SSD.
4. Connect the antenna cable to the RTL-SDR.
5. Use a short shielded USB extension, approximately 1.5-3 feet, between the
   RTL-SDR and Pi when practical.
6. Use wired Ethernet rather than Wi-Fi where practical.

This arrangement creates useful separation without adding more RF coax loss.
Additional coax is not recommended solely to move the antenna farther from the
Pi.

## Attic temperature concern

The Raspberry Pi 5 is specified for an ambient operating range of
**32-158 degrees Fahrenheit**. Its processor begins thermal throttling at
approximately **176 degrees Fahrenheit** and throttles further at approximately
**185 degrees Fahrenheit**.

Official references:

- Raspberry Pi 5 product brief:
  <https://pip-assets.raspberrypi.com/categories/892-raspberry-pi-5/documents/RP-008348-DS-4-raspberry-pi-5-product-brief.pdf>
- Raspberry Pi thermal guidance:
  <https://www.raspberrypi.com/news/heating-and-cooling-raspberry-pi-5/>

A Chicago attic can potentially exceed the Pi's rated ambient temperature in
summer. Active cooling cannot reduce equipment temperature below the attic's
ambient air temperature. Heat can also affect the SDR oscillator and overall
receiver stability.

For that reason, the preferred installation is:

- Antenna in the attic.
- RTL-SDR close to the antenna.
- Shielded active USB cable down to the Raspberry Pi.
- Raspberry Pi in a conditioned room, with active cooling and wired Ethernet.

## If the Raspberry Pi must remain in the attic

Use all of the following safeguards:

- Official Raspberry Pi Active Cooler or a quality fan-equipped case.
- A ventilated, dust-resistant enclosure that does not trap attic heat.
- Official 27-watt Raspberry Pi power supply.
- Continuous temperature monitoring.
- Monitoring for thermal throttling and undervoltage events.
- An alert threshold comfortably below **158 degrees Fahrenheit** ambient or
  **176 degrees Fahrenheit** processor temperature.
- A plan to relocate or shut down the system during extreme attic
  temperatures.

Useful monitoring commands include:

```bash
vcgencmd measure_temp
vcgencmd get_throttled
```

The Raspberry Pi documentation explains the temperature and throttling status
interfaces here:

<https://www.raspberrypi.com/documentation/computers/raspberry-pi.html>

## Final recommendation

Do not place the Raspberry Pi in the attic merely to keep it close to the
antenna. Keep the antenna and RTL-SDR close together, extend USB to a
conditioned location, and connect the Pi to the network through wired
Ethernet. If running USB between floors is impractical and the Pi must be in
the attic, use active cooling and temperature/throttling monitoring from the
start.
